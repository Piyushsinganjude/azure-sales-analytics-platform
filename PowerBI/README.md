# GlobalMart Sales Analytics Dashboard

The Power BI report connects to the Gold star schema generated by the GlobalMart Azure Data Engineering project.

## Key Metrics
- Total Net Sales
- Total Orders
- Units Sold
- Average Order Value

## Visualizations
- Sales trend over time
- Sales by product category
- Sales by region
- Monthly sales trend

## Interactive Filters
- Year
- Product category
- Region

The report demonstrates how curated lakehouse data can support interactive retail sales analysis.
